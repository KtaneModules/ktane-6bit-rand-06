On the Subject of 6-Bit Assembly

Your flavor text should go here.

Module uses ☼## to show its bytes as opposed to $## as usual. Every byte is 6 bits and every word is 2 bytes.

Module consists of 3 screens: Data screen, Command screen, Binary screen; and 2 buttons: 0 and 1.

Initially, data screen shows 64 bytes of DATA block, as 64 bytes of COLOR block. COLOR is immutable.

Pressing Binary screen will show you PROG0 block, whopping 64 words of memory for your very own program! That's not enough for you? Don't worry! Pressing Binary screen when current input is 1 will send you to the other program block, because there's two of them. The second block, PROG1, also contains 64 words!

To go back to DATA, press Binary when input is empty. To clear the input - press Command. However, if you try to clear the input that is already empty, you will change insertion mode (INSERT/REPLACE), default being REPLACE. To delete the command at cursor, press Binary when input is 0. To run the code, press Command while the DATA block is shown. To stop running, press Command again.

Your goal is to write some code that not only successfully completes the task, but also safely stops the CPU by going into infinite loop (the easiest solution for that is RJMP ☼00 in the place where you want to finish the program). Remember that if CPU goes out of the either block or encounters an invalid opcode, the module will strike. Those are the only 2 cases of module striking. THIS MEANS THAT CPU IS NOT GOING TO AUTOMATICALLY JUMP TO PROG1 IF IT GOES BEYOND ☼77 AT PROG0!

Tasks

Tasks require some parameters. R* means register with some number (R0-R7), A* means address (☼00-☼77), V* means constant value (☼00-☼77), N* also means some constant, it's ☼00-☼77 unless stated otherwise.

Data[A*] means the byte of DATA at address A*. All values mentioned in a statement are the initial ones (before the program runs), unless stated otherwise. Ranges of bytes wrap around: the byte after ☼77 is ☼00.

*a means that the value is taken from first byte of task info, *b - from second byte, *c - from third, ..., *g - from seventh. Zeroth byte is task number (0 - <amount of tasks - 1>)

To get the value in its range, modulo it by amount of possible values for this value, unless stated otherwise.

Parameters are taken from column of position of first vowel in SN, else position of first even number in SN, else position 7. Going from top to bottom, if parameter modulo 8 is equal to any previous parameter modulo 8, then add 1 to parameter and modulo it by 64 until it's modulo 8 value is unique.

If parameter is equal to 0 (either initially or after editing), add 8 to it.

If program completes the task with current data/registers, module will generate another 5 iterations of program with random data/registers. If program passes all 5 iterations, module will solve.

Amount of tasks is 26, the list goes as follows:

Task №Problem Statement
0Rearrange the values of [Ra, Rb, Rc] so Ra contains the smallest value, Rc - the largest value, Rb - the remaining value.
1Set Rd to median of [Ra, Rb, Rc].
2Set Rb to amount of Collatz conjecture mod64 steps* for Ra to reach 1. If the sequence never reaches 1, set Rb to 63.
3Set Rc to |Ra - Rb|, Rd to (Ra + Rb) mod 64, and Re to 1 if Ra + Rb is even, otherwise to 0.
4Rotate the 6-bit value of Ra by Nb bits (Nb is 0-5): to the left if Vc is even, to the right if Vc is odd.
5Set Rb to the amount of 1 bits in Ra.
6Set Rb to 1 if Ra is a power of two (1, 2, 4, 8, 16 or 32), otherwise set Rb to 0.
7Set Data[Ac] to (Data[Aa] + Data[Ab]) mod 64. Set Rd to 1 if Data[Aa] + Data[Ab] is at least 64 (carry occurred), otherwise to 0.
8If Ra > Rb, swap the values of Ra and Rb. Otherwise leave them unchanged.
9Set Rc to 1 if Data[Aa] > Vb, to 0 if Data[Aa] = Vb, and to ☼77 (-1) if Data[Aa] < Vb.
10Set Rc to the sum of Nb bytes of DATA starting at Aa, modulo 64.
11Set Rc to the maximum value among Nb bytes of DATA starting at Aa. If Nb is 0, set Rc to 0.
12Set Rd to the address of the first byte equal to Vc among Nb bytes of DATA starting at Aa. If there is no such byte, set Rd to ☼77.
13For each of Nb bytes of DATA starting at Aa: set the byte to Vc if its address is even, or to Vd if its address is odd.

Collatz conjecture mod64: if n is even, next step is n/2, else (3n+1)%64.

Opcodes

Each opcode is 1 word long, no exceptions. When you'll try to input the 12 bits of a word in any of PROG blocks, module will show the readable assembly function. However, if the opcode is not valid, then module will show its octal value with a question mark (for example: ☼3300?). Press 1 to accept the input and 0 to reset it.

Address Z is the R7 value.
